# Ravena Gabs — Fan Site

Site de fã dedicado à criadora conhecida nas redes como Ravena Gabs.

## Estrutura

```text
Ravena-Gabs-Site/
├── index.html
├── sobre.html
├── galeria.html
├── .nojekyll
├── README.md
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── app.js
```

## Páginas

- `index.html` — página inicial, apresentação e trajetória.
- `sobre.html` — informações públicas e linha do tempo.
- `galeria.html` — galeria de imagens e área de vídeos/TikTok.
- `assets/css/style.css` — estilos, responsividade e efeitos visuais.
- `assets/js/app.js` — cursor personalizado e lightbox da galeria.

## Publicação no GitHub Pages

O projeto é um site estático e está preparado para ser colocado diretamente na raiz de um repositório GitHub.

1. Crie um repositório no GitHub.
2. Envie **todos os arquivos e pastas deste projeto**, mantendo a estrutura acima.
3. Confirme que `index.html` está na raiz do repositório.
4. Abra `Settings` → `Pages`.
5. Em `Build and deployment`, escolha `Deploy from a branch`.
6. Selecione a branch `main` e a pasta `/ (root)`.
7. Salve e aguarde a publicação.

## Observação sobre imagens

Algumas imagens são carregadas por URLs externas. Portanto, o site precisa de internet para exibi-las corretamente. O projeto é não-oficial e não representa a criadora.
